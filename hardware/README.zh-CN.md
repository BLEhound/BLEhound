# BLEhound 硬件

BLEhound 嗅探器的开源硬件:围绕 **nRF54LM20A** SoC + **nRF21540** 前端模块(PA/LNA,提升距离与灵敏度)的 USB dongle。许可证 [CERN-OHL-S-2.0](LICENSE)。

## 版本

| 文件夹 | 内容 | 可投产? |
|---|---|---|
| [`v1/`](v1/) | **目前唯一投产的板子**(嘉立创 0908)——Gerber、BOM、坐标、装配、嘉立创专业版源 | ⚠️ 有已知缺陷——三机模式需返工(单片可用) |
| [`v2-wip/`](v2-wip/) | 把 V1 修正做进 PCB 的改版——**布线未完成** | ❌ 不要投产 |
| [`case/`](case/) | 3D 打印外壳(OpenSCAD + STL + 切片 3MF)——与版本无关 | ✅ 两版通用 |

> **哪块板真能用?** 原始 V1 只有**单片抓包**可用。首批板有两处引脚级缺陷,会破坏**三机**模式。想要可用的三机硬件,只能**等 V2 改版**(尚未布线),或用**改过的 V1**(按飞线修正返工过、或购入已修改的 V1 单元)。详情与接线图见 [`v1/README.zh-CN.md`](v1/README.zh-CN.md)。

## 板子概览

- **SoC:** nRF54LM20A(BLE 5.x/6.x)。固件也能跑在 nRF52840 上。
- **前端:** nRF21540 FEM(PA + LNA)——链路预算优于裸电台嗅探器。
- **主机:** USB CDC 串口到 PC / Wireshark。
- **多板:** 每片 SWD 排针,外加 SYNC 线 + 片间 SPI,三片可对齐时基做同步多信道捕获。

## 为什么有两个版本

首批(V1,0908)已投产,但有两处引脚级缺陷,会破坏三机同步模式(单片抓包正常)。所以原始 V1 **不是**可用的三机板——需要在调试排针上飞线返工(见 [`v1/README.zh-CN.md`](v1/README.zh-CN.md))。**V2** 把这些修正直接做进 PCB、从而免返工,但布线尚未完成([`v2-wip/`](v2-wip/),不要投产)。**所以想要可用的三机硬件:等 V2,或用改过的 V1。**
