# BLEhound 外壳（方案 A）· 打印与装配说明

外形 75 × 65 × 19.6 mm，两件：底壳 + 盖板。4 颗 M3 从底面拧入，顶面只有 4 个 LED 孔。
分模线放在 SMA-KWE 螺纹轴心（板面上 6.0 mm），三个 SMA 孔上下各半圆；USB-C 走后墙 9.8 × 4.0 缺口。

## 2. 拓竹 P2S 打印步骤（不用开电脑软件）

1. 按机器上装的耗材选一个文件（PLA 或 PETG），拷到打印机的存储卡根目录（P 系列是机身侧面的 microSD 卡；若是 USB 口就拷 U 盘）。
2. 确认机器上装的是**纹理 PEI 板**（黑色磨砂那块）。有 AMS 的话，对应槽的材质设成 PLA / PETG。
3. 插卡 → 触摸屏「文件」→ 存储卡 → 选文件（会显示两件的缩略图）→ 下一步 → 勾「热床调平」→ 开始。
4. 机器自动预热、调平、开打。前两层（约 2 分钟）看一眼没翘边即可离开。
5. 打完等热床降到 40 ℃ 以下，**把板拿下来掰弯**，零件自己弹开，不要用铲子抠。

可能出现的提示：
- 「打印板类型不匹配」：机器上不是纹理 PEI 板。换板；或点继续（光面 Cool Plate 打 PLA 要先涂固体胶）。
- 「耗材不匹配」：不是拓竹 PLA Basic。其它牌子 PLA 点继续即可，温度通用（220 / 55 ℃）。
- PETG：打前在板上薄涂一层固体胶，否则 PETG 在纹理板上粘得过牢。
- PLA 打印时把前门打开或顶盖玻璃拿掉（封闭仓太热会让 PLA 变软）；PETG 关门打。

## 3. 五金

| 项目 | 规格 | 数量 |
|---|---|---|
| 平头（沉头）螺丝 | M3 × 12（最长 14） | 4 |
| 热熔螺母 | M3 × 4 × 5（外径 4.6），底孔 Ø4.0 | 4 |
| 硅胶脚垫 | Ø8 × 1.5 | 4 |
| SMA 螺母 + 弹垫 | 连接器自带，可选 | 3 |

## 4. 装配顺序

1. 盖板 4 个螺柱底部压入热熔螺母：烙铁 220～250 ℃ 顶着螺母垂直压进 Ø4.0 孔，压到与柱面平。
2. 先不放板，把盖板扣到底壳上试一下松紧（盖板内沿伸进底壳 1.5 mm）。
3. PCB 放进底壳：**USB 端先斜着**让 USB-C 座钻进后墙缺口（座只进墙 0.9 mm，倾 5° 就够），再把天线端落下，3 根 SMA 螺纹落进前墙下半圆。
4. 盖上盖板，上半圆合拢，螺柱对准板孔。
5. 整体翻面，4 颗 M3 × 12 从底面拧入（不要拧过 14 mm 长的螺丝，会顶穿盖板）。贴脚垫，脚垫位在四角内侧，不压螺丝。
6. 拧 SMA 螺母（在墙外，同时把上下壳压在一起），装天线。墙外可用螺纹 5.0 mm，螺母 2.2 后剩 2.8 给天线内螺母。

按键（BOOT / RESET）和 SWD 排针在壳内，需要时拧 4 颗螺丝掀盖。

## 5. 试装后可能要调的参数（改 `blehound_case_A.scad` 顶部）

| 现象 | 参数 | 默认 | 建议 |
|---|---|---|---|
| 板子放不进 / 太松 | `clr` | 0.5 | ±0.2 |
| 盖板扣不进 / 太松 | `lip_clr` | 0.2 | 0.3 / 0.1 |
| SMA 螺纹在半圆里偏高或偏低 | `sma_axis_z` | 6.0 | 焊好后卡尺量螺纹中心到板面（孔 Ø7.4 留了 ±0.5） |
| USB-C 线插不到底 | `usb_cut_w` / `usb_cut_h` | 9.8 / 4.0 | 各 +0.5 |
| 以后要贴 ANT2（J2/J5/J8） | `ant2_slots` | false | true，重打两件 |
| 想在顶面开 BOOT/RESET 针孔 | `pin_holes` | false | true |

重出模型与切片（已装 OpenSCAD 2021.01 和 Bambu Studio）：

```
"C:\Program Files\OpenSCAD\openscad.com" -o blehound_tray.stl -D "part=\"tray\"" blehound_case_A.scad
"C:\Program Files\OpenSCAD\openscad.com" -o blehound_lid.stl  -D "part=\"lid\""  blehound_case_A.scad
```

切片：打开 Bambu Studio → 打印机 P2S 0.4 → 导入两个 STL（问「作为整体」选否）→ 工艺「0.20mm Standard」改墙 3、顶底 4/4、填充 20%、支撑关 → 切片 → 导出切片文件到卡；或直接「打印」发送到机器。

## 6. 依据

- 板：70 × 60 × 1.6，M3 孔 (4,4) (66,4) (4,47.1) (66,47.1)，坐标来自 SMT 坐标文件（x = MidX − 113.5，y = MidY + 135）。
- SMA-KWE 外螺内孔弯头：总长 14.5，牙长 8.5，本体 6 × 6 × 9.2，针 3.5，脚距 5.1 × 5.1；本体前脸在板边内 1.0，螺纹伸出板边 7.5，轴心离板面 6.0。
- USB-C 座：8.94 × 7.35 × 3.26，伸出板边 1.4（实测）。
- 排针 2×5：高 8.5（最高件），内腔净高 10.0；板下引脚尾留 4.0。
