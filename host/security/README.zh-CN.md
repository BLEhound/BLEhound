# 安全工具

用于 BLE 链路分析的密码学辅助工具。这些是嗅探器的标准能力（等同于 `crackle`），
仅供经授权的安全研究与互操作性测试使用。

- `ble_crypto.py` —— BLE 配对 / 加密原语（AES-128、传统配对用的 `c1`/`s1` 函数、
  LE 链路加密用的 AES-CCM）。已对照 Bluetooth Core Spec 测试向量验证。
- `crack_legacy.py` —— 被动式传统配对恢复：从一次抓到的配对中暴力破解临时密钥
  （Temporary Key，TK）以推导出 STK，从而解密该会话。

## 重要限制

- 只有**传统配对**（Legacy pairing，BLE 4.0/4.1）可被被动破解。
- **LE 安全连接**（LE Secure Connections，BLE 4.2+，P-256 ECDH）在**数学上**
  就无法被被动破解 —— 任何嗅探器都做不到。如果你通过其它合法途径拿到了 LTK，
  仍可把它喂给 Wireshark 来解密。

## 负责任地使用

仅可将这些工具用于你自己拥有或已获明确授权测试的设备。未经授权抓取、解密或存储
第三方设备的流量，在你所在的司法管辖区内可能属于违法行为。你需为如何使用这些工具
负责。
